# LLM
__LLM（Large Language Model，大语言模型）__，本质上是一种能够“理解和生成人类语言”的 AI 模型。

> LLM = 根据上下文预测下一个最可能出现的词

比如你输入：

> 今天天气很好，我想去

模型会预测下一个词可能是：

* 散步 ✅
* 公园 ✅
* 吃饭（也可能）

它不是“真正理解世界”，而是基于概率在“接话”。

## LLM 的代表模型有哪些？

常见的 LLM：

* GPT-4 / GPT 系列
* Claude
* Gemini

# Prompt

> “Prompt”（提示词）是你和 AI（尤其是大语言模型）沟通的输入指令。

简单说：

👉 你写给 AI 的话，就是 prompt；AI 的回答，是对 prompt 的响应。

例如：

* 你问：“今天天气怎么样？” → 这是一个 prompt
* 你说：“帮我写一篇关于环保的作文” → 也是 prompt
* 你输入一段代码让 AI 帮你修改 → 还是 prompt

## 一个好的 Prompt 通常包含什么
你可以用一个简单结构来理解：

1. 角色（Role）

让 AI 知道自己是谁

> 你是一名 C# 开发工程师

2. 任务（Task）

你要它干什么

> 设计一个用户管理模块

3. 上下文（Context）

你的背景信息

> 这是一个企业内部管理系统，需要支持用户的增删改查

4. 约束（Constraints）

限制条件

> 使用 C#，遵循 DDD + Clean Architecture

5. 输出格式（Output）

你希望它怎么回答

> 用分层结构说明，并给出目录结构

组合起来就是：

```
你是一名 C# 开发工程师，
帮我设计一个用户管理模块，

背景：
- 企业内部管理系统
- 需要支持用户的增删改查

要求：
- 使用 C#
- 遵循 DDD + Clean Architecture

输出：
- 给出目录结构
- 解释各层职责
```

## Prompt的常见类型
### 1. 指令型（Instruction）

最常见

> 帮我写一个对象池

### 2. 示例型（Few-shot）

给例子，让 AI 模仿
```
输入：1+1
输出：2

输入：2+2
输出：
```

### 3. 角色扮演（Role Play）

比如：

* 扮演《赛博朋克:边缘行者》中的 Lucy
* 扮演《命运石之门》中的 牧濑红莉栖

👉 用来控制风格和语气

### 4. 思维链（Chain of Thought）
让 AI 分步骤思考

> 请一步一步分析这个问题

## Prompt 很重要
因为：

👉 AI 的能力上限 ≈ Prompt 的表达能力

同一个模型：

* 垃圾 Prompt → 垃圾结果
* 好 Prompt → 专家级输出

这也是现在所谓的：

👉 Prompt Engineering（提示词工程）

## 高质量问法
```
你是一名有经验的 C# 开发工程师，

我正在开发一个企业内部管理系统，
需要实现用户管理模块（支持用户的增删改查、角色分配等功能）

需求：
- 支持用户的增删改查
- 支持角色分配与权限管理
- 遵循 DDD + Clean Architecture
- 区分 Data / Domain / Application / Infrastructure

请输出：
1. 模块划分（目录结构）
2. 核心类设计（User、Role、UserService 等）
3. 关键交互流程（新增用户、分配角色）
```
